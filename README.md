## 一、系统简介

星狐云陪玩点单系统是一款面向游戏陪玩 / 陪练场景的一体化点单平台。用户可以浏览陪玩、选购服务并下单支付，陪玩接单后提供服务，完成后平台自动抽成分账。系统同时支持用户端与陪玩端双角色，并配备完整的运营管理后台。

## 二、前台功能

- **首页 / 找陪玩**：浏览陪玩列表，按游戏、技能等条件筛选查找。
- **直接点单**：购买平台打包好的点单套餐，快速下单。
- **我的订单**：下单、支付、取消、确认完成、评价与退款。
- **钱包**：账户余额、充值、提现、收支明细。
- **接单大厅 / 陪玩中心**：陪玩角色抢单、管理技能与收益。
- **用户中心**：登录注册、个人资料、工单反馈。

## 三、后台功能

- **数据概览**：订单、成交额、待办事项等运营看板。
- **交易类**：订单管理、工单管理、充值审核、提现审核、评价管理。
- **运营类**：公告管理、广告管理、点单套餐、游戏管理、技能管理。
- **用户类**：用户管理、陪玩管理（含审核）。
- **系统类**：支付设置、平台设置、授权管理、操作日志、账号设置。

## 四、技术特点

- 原生 PHP + MySQL 开发，无需框架与 Composer，部署简单。
- 响应式界面，同时适配 PC 端与手机端。
- 订单状态机完善，覆盖下单、支付、接单、完成、退款全流程。
